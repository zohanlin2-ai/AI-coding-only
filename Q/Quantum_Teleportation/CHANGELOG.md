# Changelog

## [1.1.0] - 2026-05-08

### Added
- Added `README.md` with project overview and quick start instructions.

## [1.0.0] - 2026-04-23

### Added
- Python implementation of the Quantum Teleportation protocol using Qiskit (`quantum_teleportation.py`).
- Automated verification system that reverses state preparation to validate Bob's final qubit state.
- Support for Qiskit 1.0+ dynamic circuits using `if_test` for conditional corrections.
- Initial project documentation focusing on Quantum Teleportation concepts.
- `quantum_teleportation_project.md` describing the basic flow and mathematical representation.

# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2026-05-08

### Added
- Created `README.md` to provide an overview and quick start guide for the project.

## [0.2.0] - 2026-04-23

### Added
- 3-qubit implementation of Grover's Algorithm in `grover_s_algorithm.py`.
- Documentation for the 3-qubit search case in `grover_s_algorithm_project.md`.
- Automated result visualization saving to PNG files.
- New result images: `grover_2qubits_result.png` and `grover_3qubits_result.png`.

### Changed
- Refactored `grover_s_algorithm.py` to use modular functions and a centralized simulation runner.
- Updated project documentation to include complex search examples.

## [0.1.0] - 2026-04-23

### Added
- Initial project structure for Grover's Algorithm simulation.
- `grover_s_algorithm.py`: Python script using Qiskit to implement and simulate Grover's search algorithm.
- `grover_s_algorithm_project.md`: Project documentation including algorithm concepts and example code.
- `grover_result.png`: Visualization of simulation results.

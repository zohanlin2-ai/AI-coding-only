1. 多智能體互動時序圖 (Sequence Diagram)

展示使用者啟動對話後，Streamlit UI、AI 代理、中央協調器與 LLM API 之間的核心異步通信與生命週期委派流程。

sequenceDiagram autonumber actor User as 使用者 participant UI as Streamlit UI (app.py) participant Agent as AI 代理 (ai_agent.py) participant Orch as 中央協調器 (orchestrator.py) participant LLM as API 提供商 (Gemini/OpenAI/Ollama等) User->>UI: 配置參數並點擊 "開始對話" / "繼續對話" activate UI UI->>UI: 初始化狀態，設定 session_status = "running" UI->>UI: 啟動即時倒數計時器 loop 對話進行中 (is_running) UI->>UI: 於畫面渲染該角色 "打字中..." 動態特效 UI->>Agent: 呼叫 get_response(prompt, system_instruction) activate Agent alt 供應商 == Ollama (本地端) Agent->>LLM: 呼叫本地接口 (傳遞 think=False & max_tokens=1024) else 供應商 == 其他雲端 API Agent->>LLM: 傳遞 API 金鑰與對話 Context end activate LLM LLM-->>Agent: 回傳生成之對話內容 (Content / Reasoning) deactivate LLM Agent-->>UI: 回傳清洗後之發言文字 deactivate Agent UI->>UI: 將訊息加入 chat_history，並渲染對話泡泡與供應商標註 alt 發言順序 == 輪流模式 (Sequential) UI->>UI: 計算下一位發言者索引: (當前索引 + 1) % 總人數 else 發言順序 == 點名接力模式 (Nomination) UI->>UI: 使用正規表達式解析發言中是否包含 "@角色" opt 解析成功且角色存在 UI->>UI: 設定下一位發言者為被點名之角色 end else 發言順序 == 中央協調模式 (Orchestrator) UI->>Orch: 呼叫 get_next_speaker(對話歷史, 候選角色群, API金鑰) activate Orch Orch->>LLM: 傳送協調提示詞 (Orchestration Prompt) 與完整歷史 activate LLM LLM-->>Orch: 回傳決定接話的角色索引 (JSON / 數字) deactivate LLM Orch-->>UI: 回傳下一位發言者的索引值 deactivate Orch end UI->>UI: 發言間隔延遲 (Pacing Delay: 1~15秒) opt 時間結束 (Timeout) 或 使用者點擊 "🛑 停止對話" UI->>UI: 結束運行迴圈，設定 session_status = "post_dialogue" Note over UI, User: 進入對話結束決策畫面 (顯示五種選項) end end deactivate UI

Illustrates the system setup and agent tick simulation loop lifecycle:

  • start.py initiates setup health check.
  • M8 Engine spawns background Streamlit.
  • M4 coordinates multi-agent tick iterations.
  • M2 fetches ChromaDB semantic memories & queries Ollama.
  • M5 rules validate actions & apply decay/mana regen.
  • M6 saves time metadata and snapshots to disk.

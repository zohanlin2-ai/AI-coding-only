# Speak A Word
An early language learning Flutter application specifically designed for infants around one year old.

## Project Goals
This application aims to help infants begin their language journey through single words or simple vocabulary. Since infants have short attention spans and are in a critical period for linking images with sounds, the design emphasizes "Large Images, Clear Pronunciation, and Single Focus."

## Main Features
*   **High-Quality Flashcards**: Full-screen beautiful images paired with standard Chinese, English, and Japanese audio pronunciation.
*   **Automatic Language Management**: Automatically identifies the accent based on the input word, with a manual correction toggle for a streamlined experience.
*   **Smart Learning Management**: Start a session by simply checking specific words in the preparation list; supports loop-learning mode.
*   **Progress Tracking & Reset**: Records exposure counts for each word; allows individual or bulk reset of learning states at any time.
*   **Cross-platform & Offline Support**: Supports Android, Windows, Linux, and Web, with data stored in a local database for a smooth experience.

## Technical Architecture
- **Framework**: Flutter (Dart)
- **State Management**: Riverpod
- **Local Database**: SQLite (sqflite)
- **Speech Synthesis**: Flutter TTS
- **Image Source**: Unsplash API (Stable, high-quality image library)

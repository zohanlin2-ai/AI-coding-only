# Speak A Word (寶寶學說話)

一款專為一歲左右嬰兒設計的早期語言學習 Flutter 應用程式。

## 專案目標

此應用程式旨在幫助一歲左右的嬰兒透過單字或簡單詞彙開始學習語言。一歲嬰兒的專注力短暫且處於圖像與聲音的連結期，因此設計上強調「大圖像、清晰發音、單一焦點」。

## 主要功能
*   **高品質單字卡**：全螢幕精美圖片，配合標準中、英、日語音朗讀。
*   **全自動語言管理**：輸入單字自動識別口音，並提供手動校正鈕，實現極簡操作。
*   **智慧學習管理**：在備課清單勾選特定單字即可開課，支援循環學習模式。
*   **進度追蹤與重置**：記錄學習曝光次數，隨時可以單一或全部重置學習狀態。
*   **跨平台與離線支援**：支援 Android, Windows, Linux 與網頁版，資料儲存於本地資料庫，確保流暢體驗。

## 技術架構
- **開發框架**：Flutter (Dart)
- **狀態管理**：Riverpod
- **本地資料庫**：SQLite (sqflite)
- **語音合成**：Flutter TTS
- **圖庫來源**：Unsplash API (穩定高品質圖庫)

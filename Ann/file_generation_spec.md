# File Generation Module Specification

## 1. Purpose

This document defines the specification for the **File Generation** module in the Ann AI assistant. 

The goal is to allow users to easily save (export) code and document blocks generated by the AI assistant directly to their local filesystem. The UI will parse markdown code blocks in the AI's response and render them as custom code viewer widgets, complete with a language badge and a "Save File" button.

---

## 2. Scope

### 2.1 In Scope
- **Markdown Code Block Parsing**:
  - Automatically scan incoming assistant messages for markdown code blocks (fenced with triple backticks ` ```lang `).
  - Split messages into alternating sequences of plain text blocks and styled code blocks.
- **Custom Code Block Widget (`CodeBlockWidget`)**:
  - Render code blocks in a dedicated container with a distinct background (`#1E222A`).
  - Display a top header bar containing:
    - The detected language badge (e.g., `PYTHON`, `C++`, `HTML`).
    - An interactive **"Save" (💾 另存新檔)** button.
  - Display the code in a read-only scrollable view with a monospace font.
- **File Dialog & Save Interaction**:
  - Clicking the "Save" button triggers a standard system save file dialog (`QFileDialog.getSaveFileName`).
  - Automatically suggest file filters and extensions based on the block's programming language.
  - Write code contents to the selected local path with UTF-8 encoding.
- **Supported Formats for Generation**:
  - **Code**: `.py`, `.c`, `.cpp`, `.java`, `.sh` (or `.bash`), `.js`, `.ts`, `.sql`.
  - **Markup & Styling**: `.html`, `.xml`, `.css`.
  - **Data & Config**: `.json`, `.yaml` (or `.yml`), `.toml`, `.env`, `.ini`, `.cfg`.
  - **Documents**: `.md`, `.txt`.

### 2.2 Out of Scope
- Direct background file creation without user confirmation (except for future agent features).
- Syntax highlighting within the code editor view (TBD for future GUI improvements).

## 3. UI/UX Design

### 3.1 Message Layout Decomposition
When the assistant returns a message containing code:
```
[Original AI Response]
Here is the code:
```python
print("Hello World")
```
Hope this helps!
```

Ann's UI decomposes this message into a vertical stack of widgets inside the message bubble:
1. `QLabel`: "Here is the code:"
2. `CodeBlockWidget`: Styled editor showing `print("Hello World")` with Python header and Save button.
3. `QLabel`: "Hope this helps!"

### 3.2 CodeBlockWidget Styling
- **Container**: Rounded QFrame with dark slate background (`#1E222A`) and subtle border (`#2D3139`).
- **Header Bar**:
  - Height: $28\text{px}$.
  - Background: `#181A1F`.
  - Language label: Left-aligned, bold, gray text (`#ABB2BF`), font size $11\text{px}$.
  - Save button: Right-aligned, text link style `💾 另存新檔`, blue text (`#61AFEF`) changing to cyan on hover.
- **Code View**: Monospace font (`Consolas`, `Courier New`), padding $8\text{px}$, text color `#ABB2BF`.

### 3.3 Extension Filters Mapping

When the user clicks the "Save" button, the file dialog filter defaults to the mapped type:

| Markdown Tag | Default Extension | File Dialog Filter |

| `c` | `.c` | `C Source Files (*.c *.h)` |

    # Regex to capture: ```lang\ncode\n```
    pattern = r"```([a-zA-Z0-9+#-]+)?\n(.*?)\n```"
    # Returns alternations of text and code blocks
```

### 4.2 Class Specifications

#### `CodeBlockWidget(QFrame)`
Visual container for code blocks.
- `__init__(self, language: str, code_content: str, parent=None)`
- Layout: Vertical layout.
  - Header: QHBoxLayout containing language label and Save `QPushButton`.
  - Body: QTextEdit (read-only, flat background, scrollbar enabled).
- Handles click on "Save" button, invokes `QFileDialog.getSaveFileName`, maps language to filter, and writes to disk.

#### `MessageBubble(QFrame)`
Updated to accept a decomposed list of blocks. Instead of a single `QLabel`, its layout contains multiple labels and `CodeBlockWidget`s arranged vertically.

## 5. Verification & Testing

### 5.1 Automated Unit Tests
- Test cases checking markdown parser splits text and code blocks correctly.
- Test cases checking language-to-extension mappings.

### 5.2 Manual Verification Scenario
1. Run Ann in GUI mode.
2. Ask Ann: "Write a python function to add two numbers, and a small html page."
3. Verify that:
   - The Python code and HTML code are rendered in separate dark-themed boxes.
   - Each box has a `💾 另存新檔` button.
4. Click `💾 另存新檔` on the Python block.
   - Verify the save file dialog defaults to naming with a `.py` extension.
   - Save the file and confirm the contents match the code block.
